# The Isle Bosch Overlay Setup

Run the setup package once.

That installer:

- copies The Isle Bosch Overlay v2 onto your Desktop
- removes older known v1/Reptarland overlay installs and old desktop launchers
- creates fresh desktop launcher shortcuts
- adds a Start Menu entry
- includes full v2 update notes in `RELEASE_NOTES_v2.md`

After install, use `The Isle Bosch Overlay Launcher` whenever you play.

The launcher:

- starts Mumble if it is not already running
- starts the Bosch overlay hidden in the background
- keeps the overlay available with the in-game hotkeys

Default hotkeys:

- `F8` toggles compact and full map modes
- `F9` shows or hides the overlay

Map overlay buttons:

- Open the full map with `F8` to access Migration, Patrol, Sanctuary, Gastro, Salt, and Mud toggles.
- Compact mode hides these buttons to keep the small overlay clean.
