# The Isle Bosch Overlay Setup

Run the setup package once.

That installer:

- copies the overlay to your local app data folder
- creates a single launcher shortcut on your desktop
- adds a Start Menu entry

After install, use `The Isle Bosch Overlay Launcher` whenever you play.

The launcher:

- starts Mumble if it is not already running
- starts the Bosch overlay hidden in the background
- keeps the overlay available with the in-game hotkeys

Default hotkeys:

- `F8` toggles compact and full map modes
- `F9` shows or hides the overlay
