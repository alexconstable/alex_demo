# Nexus Upload Notes

This repository contains the full source code for The Isle Bosch Overlay v2 and the scripts used to build the Windows desktop app and setup executable.

Useful review files:

- `README.md`: project overview, feature summary, and overlay usage.
- `BUILD.md`: detailed build steps.
- `RELEASE_NOTES_v2.md`: player-facing v2 update notes.
- `SECURITY_REVIEW.md`: behavior and safety notes for mod-hosting review.

Expected build output:

```text
release\The Isle Bosch Overlay-win32-x64\The Isle Bosch Overlay.exe
dist\The-Isle-Bosch-Overlay-v2-Desktop-Setup.exe
```

The app is an external overlay, not a game-file mod or injection tool.
