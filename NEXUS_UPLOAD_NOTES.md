# Nexus Upload Notes

The Isle Prime Tracker is a portable Electron overlay for manually tracking Prime Elder checklist progress.

Scanner/review notes:

- NSIS setup `.exe` generated by Electron Builder
- no custom native addon code written by this project
- no bundled browser login or Bosch tracker webview
- no game process injection
- no game file modification
- full source included for review

Unsigned Electron apps may trigger reputation warnings because they bundle the Electron/Chromium runtime, an installer/uninstaller stub, DLLs, `.pak` files, and `app.asar`. The included SHA256 hash lets users verify that their download matches the packaged build.

Setup executable:

```text
TheIslePrimeTracker-Setup.exe
```

Hotkeys:

- `F6`: compact / expanded overlay
- `F7`: hide / show overlay
