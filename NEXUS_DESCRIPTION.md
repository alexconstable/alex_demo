# The Isle Bosch Overlay v2

The Isle Bosch Overlay v2 is a Windows desktop overlay for players who use the Bosch Island tracker on Gateway.

This release focuses on a major Vulnona-style map overhaul:

- Vulnona-style Gateway map reference and map-data alignment.
- Migration, Patrol, and Sanctuary overlays.
- Gastro, Salt, and Mud resource toggles.
- Updated drinking-water visibility for interior lakes, rivers, ponds, and puddles.
- Improved Bosch tracker calibration.
- Compact and full map modes.
- Rotating compass and clearer player/friend markers.
- Full-size Bosch login window to fix the old condensed login issue.

The overlay is external. It does not inject into The Isle, modify game files, read memory, install drivers, or bypass anti-cheat. It runs as a normal Electron desktop application.

Full source code, build instructions, security notes, and v2 update notes are included in this repository.
