# The Isle Prime Tracker

The Isle Prime Tracker is a small Windows overlay for Evrima players who want a clean, manual checklist for Prime Elder progress. It stays on top of the game, tracks your current run, and keeps previous runs available so you can swap back to them later.

## What It Does

- Opens a compact, frameless Prime Tracker overlay for The Isle.
- Tracks Prime-related objectives like perfect diet, sanctuary, hatching, growth milestones, migration zones, patrol zones, Never Infertile, and Never Muscle Spasms.
- Shows Prime progress with an orange progress bar.
- Saves multiple runs locally and lets you select or rename previous runs.
- Uses a glass-style overlay UI designed to sit alongside the Gateway map overlay.
- Can be dragged around the screen from the top header.

## Hotkeys

- `F6`: compact / expanded Prime Tracker
- `F7`: hide / show Prime Tracker

The Gateway map overlay uses `F8` and `F9`, so Prime Tracker stays on `F6` and `F7`.

## Installation

Run `The-Isle-Prime-Tracker-Desktop-Setup.exe`.

The setup extracts a `The Isle Prime Tracker` folder to your Desktop, creates a Desktop shortcut, and starts the tracker. No admin install is required.

## What It Does Not Do

- It does not inject into The Isle.
- It does not modify game files.
- It does not read game memory.
- It does not install a driver, service, scheduled task, or browser extension.
- It does not auto-update or download executable payloads after install.

This is a manual tracking overlay. You check off progress yourself as you play.

## Notes

This is an unsigned Electron app, so Windows SmartScreen or antivirus tools may show reputation warnings on first download. The app is packaged with the Electron/Chromium runtime, which is why the download is larger than a normal script or config mod.
